# Java Training

A comprehensive collection of Java programs created during Java training and practice sessions. This repository demonstrates fundamental programming concepts, problem-solving techniques, and Object-Oriented Programming (OOP) principles through practical examples and mini-projects.

## 📚 About

This repository serves as a learning resource for beginners and students who want to strengthen their Java programming skills. The programs cover topics ranging from basic syntax and user input handling to advanced concepts such as abstraction, inheritance, and polymorphism.

The code is organized by topics and training days, making it easy to follow the learning progression and understand how different Java concepts are applied in real-world scenarios.

## 🚀 Topics Covered

### Core Java Fundamentals
- Variables and Data Types
- Operators and Expressions
- Input Handling using Scanner
- Type Conversion
- Basic Calculations

### Decision Making
- If-Else Statements
- Nested If Statements
- Switch Case Statements
- Conditional Logic

### Object-Oriented Programming (OOP)
- Classes and Objects
- Constructors
- Method Overloading
- Inheritance
- Polymorphism
- Abstraction
- Method Overriding

### Advanced Java Concepts
- Abstract Classes
- Abstract Methods
- Final Methods
- Custom Object Comparison
- Package Organization
